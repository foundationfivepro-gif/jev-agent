# jev-agent defaults

A session-start note `jev hooks active` means hooks gate outbound Bash and route every subagent spawn (model plus a conclusion-only return contract); don't repeat those calls. Without it (Cowork, claude.ai, no hooks), call `jev_gate_command` before outbound commands (never run a `policy` block) and `jev_route_model` before delegating, asking for the conclusion only.

- Before reading files to find something: `jev_select_context`; read `include`, `index` only when needed.
- Before an external-effect action (send, post, delete, pay, deploy): `jev_check_action`.
